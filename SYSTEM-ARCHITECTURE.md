# System Architecture

This repository contains interconnected classroom systems designed to support student-centered learning using AI, automation, and digital publishing.

---

## Core Systems

### 1. EduFlow CMS
A classroom publishing platform where students create and publish real work.

### 2. AI Learning Integration
AI-assisted learning workflows using Gemini for reflection, writing support, and idea generation.

### 3. RPM Automation System
Google Apps Script workflow for generating structured educational reports and PDFs.

### 4. Digital Portfolio System
Public documentation of classroom implementation, student work, and learning impact.

---

## Technology Stack

- Google Apps Script
- Gemini AI
- Markdown Documentation
- GitHub
- Vercel
- HTML/CSS/JavaScript

---

## Educational Framework

The systems are built around:

- Student-Centered Learning
- Project-Based Learning (PBL)
- Reflective Practice
- Real-world Publishing
- AI-assisted Learning
