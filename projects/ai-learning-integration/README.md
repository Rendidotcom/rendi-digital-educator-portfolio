# AI Integration in Learning

Using AI tools to support student learning, reflection, and idea generation.

---

## 🎯 Purpose

To enhance student thinking, not replace it.

---

## 🤖 How AI is Used

- Assisting student writing
- Generating ideas
- Supporting reflection
- Providing feedback prompts

---

## ⚠️ Approach

AI is used as:
- Thinking partner
- Not answer generator

Students must:
- Edit outputs
- Reflect on results
- Take ownership

---

## 🧠 Learning Flow

Prompt → AI Response → Student Editing → Final Output

---

## 📊 Impact

- Students write more confidently
- Faster idea generation
- Improved reflection quality

---

## 🔥 Status

Implemented in classroom learning
