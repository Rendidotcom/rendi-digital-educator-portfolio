# Getting Started with EduFlow CMS

This guide helps educators implement EduFlow CMS in their own classroom.

---

## 🎯 What You Need

- Google Account
- Google Drive access
- Google Sheets
- Basic understanding of Google Apps Script

---

## ⚙️ Setup Steps

### 1. Prepare Google Sheet (Database)

Create a Google Sheet with columns:
- Title
- Content
- Date
- Author

---

### 2. Setup Google Apps Script

1. Open Google Apps Script
2. Create a new project
3. Paste the EduFlow backend code
4. Deploy as Web App

---

### 3. Connect Google Drive

- Upload `.docx` files to Drive
- System will convert to Google Docs
- Content will be extracted automatically

---

### 4. Connect to Blog Platform

- Use API endpoint from Apps Script
- Send data to your blog frontend (Vercel)

---

## 🔁 Workflow

Upload → Convert → Extract → Store → Publish

---

## 🚀 Result

Teachers can publish learning content in one click without manual formatting.

---

## ⚠️ Notes

- Ensure permissions are set correctly in Google Apps Script
- Always test with sample files before classroom use
